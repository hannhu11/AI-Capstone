\subsection{Quality Management}

Quality gates were automated across both research and software tracks: (1) \textbf{Cryptographic Manifests:} every GDUT dataset build logs \nolinkurl{dataset_manifest.json} and \nolinkurl{duplicate_audit.json}, while every Kaggle run logs \nolinkurl{dataset_fingerprint}, source/output checkpoint SHA-256 digests, and per-rank module inventories (\nolinkurl{architecture_rank_0/1.json}); (2) \textbf{Preflight Verification:} synthetic $2 \times 3 \times 64 \times 64$ tensor tests verify all 12 configurations (A1--A6 $\times 2$ backbones) for finite losses, non-zero custom gradients, reload equivalence, decoded shape $2 \times 9 \times 84$, and RepConv fusion parity before cloud training; (3) \textbf{CI/CD Regression:} GitHub Actions (\nolinkurl{.github/workflows/ci.yml}) runs \texttt{ruff} (\texttt{E9,F63,F7,F82}), bytecode compilation, 85 Clean-Room \texttt{pytest} cases (\textbf{84 passed, 1 skipped} in weightless stub mode), Compose validation, and \nolinkurl{Dockerfile.gateway} builds, while full workspace CPU \texttt{pytest} passes \textbf{141/141} (\textbf{140 passed, 1 skipped} in stub mode); and (4) \textbf{Document Verification:} automated LuaLaTeX + PyMuPDF checks confirm 60--100 page compliance, zero unresolved citations or \texttt{Overfull} boxes, and synchronized \texttt{.docx} export.

\subsection{Change Management and Project Closure}

Scope and architecture updates followed a four-step Change Control Protocol (Proposal $\rightarrow$ Impact Assessment $\rightarrow$ Supervisor/Team Approval in the project decision log $\rightarrow$ Versioned Cutover). Two major change requests governed the final build: \textbf{CR-01} consolidated all five-class capstone evaluations onto deduplicated GDUT-HWD across all 15 official \texttt{nvthanh2004} notebooks under digest \texttt{ce2a883e} while isolating three-seed SHWD/HHW (\textbf{Proposed V1}) inside \texttt{SHWD\_V1/}; \textbf{CR-02} reconciled legacy schematics with actual runtime layers (6$\times$RepConv across backbone+neck and BiFormerBlockLite at P5 layer 10) via \nolinkurl{GDUT_A6_YOLO11s_Overall_Simplified.pdf} and redesigned the dashboard into a Milestone/Siemens-inspired flat light interface backed by six Docker microservices and PostgreSQL 16.

Project closure is gated on five handoff checks: (1) 18-item Task 3 checklist completion (Appendix C); (2) synchronized English PDF and \texttt{.docx} export (\nolinkurl{Capstone_Thesis_Report.{pdf,docx}}, standardized archival naming); (3) green GitHub Actions CI (\texttt{84 passed, 1 skipped}) and local \texttt{141/141} CPU \texttt{pytest}; (4) verified 1-to-1 parity across all 15 public Kaggle notebooks (75/75 MATCH) and \texttt{SHWD\_V1/}; and (5) updated archival change log, slides, and backup demo video.
