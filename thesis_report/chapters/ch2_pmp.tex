\subsection{Quality Management}

Quality assurance was enforced across both the \textbf{machine learning research track} and the \textbf{software engineering track} through objective, automated verification gates:

\begin{enumerate}[leftmargin=1.8em, itemsep=3pt]
  \item \textbf{Cryptographic Provenance and Manifest Locking:} Every GDUT dataset build writes \nolinkurl{preparation_complete.json}, \nolinkurl{duplicate_audit.json}, and \nolinkurl{dataset_manifest.json}. Every Kaggle training run records the SHA-256 \nolinkurl{dataset_fingerprint}, source Stage 1 checkpoint hash, output \texttt{best.pt} hash, per-rank module inventory (\nolinkurl{architecture_rank_0/1.json}), and re-evaluated \texttt{val\_check} metrics inside \nolinkurl{run_manifest.json}.
  \item \textbf{Preflight Software Integration Testing:} Before launching full Kaggle training, \nolinkurl{GDUT_architecture_integration_check.ipynb} verifies all 12 model configurations (\texttt{A1--A6} $\times$ \texttt{YOLO11s}/\texttt{YOLOv8s}) on synthetic $2 \times 3 \times 64 \times 64$ tensors for finite forward/loss values, non-zero custom-module gradients, checkpoint save/reload equivalence, decoded output shape $2 \times 9 \times 84$, and sample \texttt{RepConv} fusion parity.
  \item \textbf{Automated CI/CD and Regression Verification:} Every commit to \texttt{main} triggers GitHub Actions (\nolinkurl{.github/workflows/ci.yml}) executing static \texttt{ruff} checks (\texttt{E9,F63,F7,F82}), bytecode compilation (\texttt{python -m compileall -q src tests scripts}), all 79 Clean-Room CI \texttt{pytest} cases (\textbf{78 passed, 1 skipped} cleanly in weightless stub mode), Docker Compose schema validation, and slim Gateway image building (\nolinkurl{Dockerfile.gateway}), while the full local workspace suite passes all \textbf{135/135} regression tests on CPU (\textbf{134 passed, 1 skipped} in stub mode).
  \item \textbf{Document Verification Gates:} This LaTeX report is compiled via \texttt{lualatex $\rightarrow$ bibtex $\rightarrow$ lualatex $\rightarrow$ lualatex} and audited by an automated PyMuPDF verification script confirming exact 100-page bounds (strictly within the 60--100 page specification), zero unresolved cross-references or citation markers, zero \texttt{Overfull} box warnings, zero stray non-English diacritics, and direct visual inspection of rendered PNG pages.
\end{enumerate}

\subsection{Change Management Process}

All changes to research scope, dataset taxonomy, architectural topology, or software interfaces followed a four-step Change Control Protocol: (1) \textbf{Change Proposal} triggered by empirical audit findings or faculty committee review feedback; (2) \textbf{Impact Assessment} quantifying effects on dataset comparability, GPU budget, and VMS API backward compatibility; (3) \textbf{Supervisor/Team Approval} logged in meeting minutes and \texttt{memory.md}; and (4) \textbf{Versioned Cutover} with explicit archival of superseded artifacts.

Two pivotal change requests shaped the final quality of Project \textbf{FA26AI16}:
\begin{itemize}[leftmargin=1.8em, itemsep=3pt]
  \item \textbf{CR-01 (Taxonomy Consolidation onto Clean GDUT-HWD 5-Class):} Following forensic audits that exposed omission noise in naively merged multi-source PPE datasets and small violation sample counts in alternate datasets, the team formally consolidated the capstone's experimental benchmark exclusively onto the clean, SHA-256 deduplicated five-class \texttt{GDUT-HWD} dataset (3,168 images, 18,849 boxes), focusing purely on safety helmet presence and four-color classification while cleanly isolating the binary \texttt{SHWD/HHW} experiments into the separate \texttt{AAIML 2027} conference track.
  \item \textbf{CR-02 (Architecture Diagram Reconciliation and Enterprise VMS Redesign):} Prior to Review 3, a code-to-diagram forensic audit revealed that legacy schematics depicted \texttt{RepConv} only in the neck and \texttt{BiFormer} inside PAN, whereas the canonical code places six \texttt{RepConv} blocks across both backbone and neck and \texttt{BiFormerBlockLite} at backbone P5 (\texttt{layer 10} on \texttt{YOLO11s}). The diagram was updated to \nolinkurl{GDUT_A6_YOLO11s_Overall_Simplified.pdf}, and following supervisor UI feedback, the AEGIS-CCTV dashboard was redesigned from a dark neon prototype into a clean Milestone/Siemens-inspired flat light enterprise VMS interface backed by a 6-microservice architecture.
\end{itemize}
